# Lista de Tarefas

App de tarefas feito com HTML, CSS e JavaScript.

## Funcionalidades

- Adicionar tarefas
- Marcar como concluída
- Remover tarefas
- Filtrar por status
- Dados salvos no localStorage

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

Baixe os arquivos e abra no navegador.
